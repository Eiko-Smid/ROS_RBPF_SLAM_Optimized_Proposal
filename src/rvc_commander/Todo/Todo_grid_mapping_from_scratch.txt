    7.1 Save map with map server


        7.1.1 Map server

            - The ros tool is "map_server"
            - The server is a ros service 
            - It get's a map and someone can receive it by calling the service
            - It has two publisher. One for publishing the "nav_msgs/OccupancyGrid" 
            - The other for publishing the "nav_msgs/MapMetaData" which is included in the "nav_msgs/OccupancyGrid " 
            - To get the map, one need to use the service "nav_msgs/GetMap"  

            Start service:

                - To start the service an existing map.yaml and the corresponding map image file need's to be loaded into the
                  node.
                - This can be done easily in a launchfile 

                Example: 

                        <arg name="map_file" default="$(find rvc_commander)/maps/cafe_map_by_gmapping.yaml"/>
                        <node pkg="map_server" name="map_server" type="map_server" args="$(arg map_file)" output="screen" />
 
        
        7.1.2 Map Saver

            - The map server also include's a tool for saving an map from a topic. The name of the tool is "map saver"
            - It subscribes from the topic "nav_msgs/OccupancyGrid". If there is a map it can be easily saved.
            
            Example (via console): 
                rosrun map_server map_saver -f mymapname
                
                -> Save it do the current terminal directory

            Status: Done


            7.1.3 Benutze Parameter um die Map zu beeinflussen 

                - Benutzt man den Map Server zum Speichern der Karte, so kann eingestellt werden, ab welcher
                  Wahrscheinlichkeit die Zellen belegt sein sollen und ab welcher frei.

                  "--occ 90":   Bedeutet die Zelle wird ab einer Belegungswahrscheeinlichkeit höher als 90 als occupied gewertet 
                                Dadruch erhält sie die Farbe schwarz
                  
                  "--free 10":  Bedeutet die Zelle wird unter einer Belegungswahrscheeinlichkeit kleiner als 90 als occupied gewertet 
                                Dadruch erhält sie die Farbe schwarz

    N.3 Drop the prior

        - If the prior probability is 0.5, then we don't need it in the update part of a cell!

        Explanation: 

            prior= 0.5 

            -> Odds(mi) = prior / (1 - prior) = 0.5 / (1 - 0.5) = 1

            odds(mi | z1:t, x1:t) = Odds(mi | zt, xt) * Odds(mi | z1:t-1, x1:t-1) * Odds(mi)
                                  = Odds(mi | zt, xt) * Odds(mi | z1:t-1, x1:t-1) * 1

            -> multiplication with one doesn't change result !
